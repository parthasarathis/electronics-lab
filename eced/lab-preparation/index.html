Experiment 01 SimulationLab CO1

Verification of KCL and KVL using LTspice

Verify signed current and voltage balances in the assigned circuit.

Before you start: Ohm’s law; reference directions; voltage polarity.

Ohm’s law and circuit basicsKCL and KVL
Pre-lab · predict and prepare
  • Mark a reference node, current arrows and voltage polarities before writing equations.
  • Write one node equation and one independent loop equation for the assigned circuit.
  • Predict what a negative current reading would mean.
During the lab · observe and record
  • Use the assigned component values and the same reference directions in the calculation and simulation.
  • Measure the required branch currents and voltage drops at the operating point.
  • Calculate a signed KCL residual and a signed KVL residual; include units.

Record these quantities

  • Branch current and reference arrow (A or mA)
  • Element voltage and polarity (V)
  • Node-current sum (A); loop-voltage sum (V)

Include the assigned circuit, component values, reference directions and units in your record.

Post-lab · compare and explain
  • Compare calculated and simulated values. Does rounding explain the residual?
  • Explain a negative reading using the chosen reference direction.
  • If a balance fails, identify one connection or sign convention to check first.
Formula reminder
Signed current and voltage sums must balance.

Experiment 02 SimulationLab CO1

Node and mesh analysis using LTspice

Solve the assigned network using node voltages and mesh currents, then compare with simulation.

Before you start: KCL; KVL; simultaneous equations.

Node analysisMesh analysis
Pre-lab · predict and prepare
  • Identify unknown node voltages and any voltage already fixed by a grounded source.
  • Choose mesh-current directions and write the shared-branch current with consistent signs.
  • Decide whether the assigned circuit needs a supernode or supermesh. Explain why.
During the lab · observe and record
  • Solve the simultaneous equations before checking the simulator output.
  • Record node voltages relative to the same reference node.
  • Convert mesh currents into physical branch currents, then compare those branch currents with simulation.

Record these quantities

  • Node voltage and reference (V)
  • Mesh current and direction (A or mA)
  • Shared-branch current; KCL/KVL residuals

Include the assigned circuit, component values, reference directions and units in your record.

Post-lab · compare and explain
  • Do node and mesh methods predict the same physical branch currents?
  • Why can a mesh current differ from the current in a shared branch?
  • Which measurement would help locate an incorrect equation sign?
Experiment 03 SimulationLab CO2

Superposition, Thevenin’s and Norton’s theorems using LTspice

Validate source contributions and terminal-equivalent circuits under the same load.

Before you start: Node or mesh analysis; source transformation.

Superposition theoremThevenin and Norton equivalentsSource transformation
Pre-lab · predict and prepare
  • Define the response quantity and the two load terminals.
  • Explain how each independent source is deactivated in an ideal circuit model.
  • Predict which quantities must agree between the original circuit and its equivalent.
During the lab · observe and record
  • Record each independent-source contribution with its sign, then add voltage or current responses.
  • Find the open-circuit voltage and equivalent resistance seen from the load port.
  • Reconnect the same load to the original, Thevenin and Norton circuits and compare terminal quantities.

Record these quantities

  • Individual and total response (V or A)
  • Thevenin voltage (V); equivalent resistance (Ω); Norton current (A)
  • Load voltage, load current and load resistance

Include the assigned circuit, component values, reference directions and units in your record.

Post-lab · compare and explain
  • Does the sum of source contributions match the full-circuit response?
  • Why must the load remain outside the equivalent-source boundary?
  • Explain why separate source powers generally cannot be added using superposition.
Formula reminder
The two equivalent forms use the same terminal resistance.

Experiment 04 SimulationLab CO3

Transient analysis of RL and RC circuits

Analyse initial values, final values and time constants of the assigned first-order circuits.

Before you start: KVL/KCL; exponential response; capacitor and inductor state variables.

RC and RL transients
Pre-lab · predict and prepare
  • State the capacitor voltage or inductor current immediately before switching.
  • Predict the state immediately after switching and the eventual DC value.
  • Find the resistance seen by the storage element for the assigned source conditions.
During the lab · observe and record
  • Choose a simulation interval and time resolution that show both the early response and settling trend.
  • Mark the theoretical time constant on the waveform.
  • Compare initial, one-time-constant and late-time values without assuming exact finite-time settling.

Record these quantities

  • Time (s); capacitor voltage (V) or inductor current (A)
  • Initial and final state values; theoretical time constant (s)
  • State at one time constant; simulated time-constant estimate

Include the assigned circuit, component values, reference directions and units in your record.

Post-lab · compare and explain
  • Compare the time-constant estimate with the theoretical value.
  • Explain why a charging curve and a discharging curve use different absolute voltage readings at one time constant.
  • How could initial stored energy change the observed response?
Formula reminder
Use the resistance seen by the storage element for the stated switching condition.

Experiment 05 SimulationLab CO4

Resonance analysis of RLC circuits using LTspice

Examine resonance and frequency response with a clearly defined circuit topology and plotted quantity.

Before you start: Complex impedance; frequency sweeps; RMS quantities.

Resonance, bandwidth and QPhasor Lab
Pre-lab · predict and prepare
  • State whether the assigned RLC circuit is series or parallel.
  • Name the quantity plotted in the frequency sweep and its units.
  • Predict whether source-current magnitude should rise or fall near resonance for the selected drive and topology.
During the lab · observe and record
  • Sweep across a range that includes both sides of resonance.
  • Record the resonant frequency and the response magnitude there.
  • If finding bandwidth, state the response and drive condition used to define its half-power points.

Record these quantities

  • Frequency (Hz); selected response and units
  • Resonant frequency (Hz); peak or minimum response
  • If applicable: lower/upper boundary frequencies (Hz)

Include the assigned circuit, component values, reference directions and units in your record.

Post-lab · compare and explain
  • Compare resonance with the ideal LC estimate and explain the assumptions.
  • Why is a source-current maximum not a universal definition of resonance?
  • Explain which measurement would justify a reported bandwidth or Q value.

Ideal LC resonance estimate; state the topology and component model used.

Experiment 06 SimulationLab CO3

AC circuit and phasor analysis using LTspice

Compare RMS magnitudes, phase angles and phasor sums in the assigned AC network.

Before you start: Sine waves; RMS; complex impedance.

Sinusoids, RMS and phasePhasor LabComplex power and power factor
Pre-lab · predict and prepare
  • Choose one phase reference and label the current/voltage directions.
  • Predict whether the relevant current leads or lags the reference voltage.
  • Write the appropriate phasor KVL or KCL equation before adding magnitudes.
During the lab · observe and record
  • Use the same frequency and RMS/peak convention in your calculation and simulation comparison.
  • Record voltage and current phase angles against the same reference.
  • Add rectangular phasor components and check the resulting magnitude and angle.

Record these quantities

  • Frequency (Hz); voltage convention (RMS or peak)
  • Voltage/current magnitudes (V, A) and phase angles (°)
  • Phasor sum and the reference directions used

Include the assigned circuit, component values, reference directions and units in your record.

Post-lab · compare and explain
  • Why can the sum of component-voltage magnitudes exceed the source magnitude?
  • Compare the phasor result with the time-domain lead/lag observation.
  • Explain how a reversed current reference changes the reported phase angle.
Experiment 07 HardwareLab CO3

Measurement of RC and RL time constants

Estimate time constants from measured charging or decay waveforms.

Before you start: First-order response; oscilloscope time/voltage scales.

RC and RL transients
Pre-lab · predict and prepare
  • Predict initial and final values for the assigned switching condition.
  • Calculate the theoretical time constant, including relevant source or winding resistance.
  • Identify the waveform level corresponding to 63.2% of a rising change or 36.8% of a remaining decay.
During the lab · observe and record
  • Use the instructor-approved circuit, instrument settings and supply limits.
  • Measure the waveform relative to its actual initial and final values.
  • Repeat the time-constant estimate and record relevant component tolerances or loading effects.

Record these quantities

  • Measured resistance, capacitance or inductance, with units
  • Initial/final state values; selected threshold level
  • Measured time interval (s); repeated estimates

Include the assigned circuit, component values, reference directions and units in your record.

Post-lab · compare and explain
  • Compare measured and predicted time constants using a stated percentage difference.
  • How might probe loading, component tolerance or coil resistance affect the result?
  • Why is one fixed voltage threshold unsuitable for every charging/discharging case?
